# Regras de negócio — Fase 2.1

## Assinaturas

Cada categoria de ocorrência terá uma configuração de participantes e etapas obrigatórias. A solicitação não entra em extração enquanto existir assinatura obrigatória pendente.

## Retenção

O prazo é configurado por categoria e aplicado pela API conforme política corporativa. Bloqueios legais suspendem descarte. Exclusão automática está fora do escopo atual.

## Downloads

Somente TI com permissão explícita pode baixar gravações. A API registra identidade, solicitação, arquivo, horário, resultado e motivo da negativa.

## Delegação

Toda substituição registra titular, substituto, escopo, início, fim e autorizador. Substitutos não podem modificar a própria autorização nem conceder privilégios administrativos.
