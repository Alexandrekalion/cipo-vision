# CIPO VISION

Fundação do CIPO VISION, com frontend independente na VM 108 e API/PostgreSQL externos.

## Estrutura

- `frontend/` — aplicação React + TypeScript + Vite.
- `backend/` — espaço reservado para a API FastAPI externa.
- `docs/` — requisitos, arquitetura e implantação.
- `infra/` — artefatos de infraestrutura, sem segredos.

O desenvolvimento e a implantação ainda não foram iniciados. Consulte `docs/requisitos.md` antes de implementar funcionalidades.
